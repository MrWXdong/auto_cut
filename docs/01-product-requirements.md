# AutoCut 产品需求文档 v0.1

## 1. 背景

企业内容团队已经在用 AI 工具提效，但大多停留在「单点工具」：一个工具做字幕，一个工具做切片，一个工具做封面，最后还要人工串起来。真正的浪费不在某一个环节，而在素材流转、版本管理、返工和交付。

AutoCut 要解决的是整条流水线，而不是再做一个剪辑按钮。

## 2. 目标用户

### 主用户：中小电商/品牌内容组（3 到 10 人）

- 每周要产出几十条短视频，分发到抖音、视频号、小红书、淘宝
- 有固定模板和品牌规范，但每次仍要人工套
- 剪辑师流动大，新人上手慢
- 老板关心的是产量、时效和外包成本

### 次用户：本地生活代运营 / MCN

- 同时服务多个商家，素材多、交付急、单条预算低
- 需要批量处理和客户隔离
- 更愿意为工具付费，是早期最现实的客户

### 暂不服务

- 专业影视后期团队：需求高度定制，标准化收益低
- 纯 C 端玩票用户：付费意愿低，获客成本高

## 3. 核心场景

1. 一条 30 分钟直播回放，自动切成 10 条 60 秒以内的竖屏片段，带字幕和封面。
2. 一条主素材，自动导出 9:16、1:1、16:9 三个版本，适配不同平台。
3. 品牌模板固定片头、片尾、字体、logo 和安全区，AI 只负责内容部分。
4. 剪辑主管审核 AI 初剪结果，打回后只重跑受影响的节点。
5. 运营查看本周产量、单条成本、返工率和任务失败原因。

## 4. 痛点排序

| 优先级 | 痛点 | 现状 | 机会 |
| --- | --- | --- | --- |
| P0 | 批量出多平台版本 | 人工重复导出 | 一次配置，多规格产出 |
| P0 | 字幕制作耗时 | 逐句核对 | ASR 加自动断句，人工只改错 |
| P0 | 长素材找高光靠人看 | 反复拖进度条 | LLM 加多模态选段，给出理由 |
| P1 | 模板和品牌规范靠记忆 | 每条都要检查 | 模板化，节点级校验 |
| P1 | 返工不可控 | 全部重剪 | 节点级重跑与版本对比 |
| P2 | 成本不透明 | 不知道钱花在哪 | 按任务、节点、模型归因 |

## 5. 产品定位

一句话：把企业剪辑部的重复劳动变成可配置、可审核、可计量的工作流。

差异化不在「AI 一键成片」，而在：

- 半自动：AI 初剪，人做最终判断
- 可解释：每个片段有推荐理由和置信度
- 可恢复：单节点失败不影响已完成部分
- 可计量：每条成片的模型成本和渲染成本可查

## 6. 功能范围

### P0：单机闭环（第 1 到 4 周）

- 素材导入：本地文件、URL
- 工作流模板：字幕流、切片流
- 节点：探测、抽音频、ASR、字幕生成、LLM 选段、裁剪、多规格导出
- 任务执行：进度事件、失败重试、断点续跑
- 命令行运行与结果目录

### P1：可交付给企业（第 5 到 8 周）

- 账号、租户、成员、角色
- 对象存储直传与预签名下载
- 任务中心：列表、详情、日志、取消、重试
- 模板管理与品牌规范（字体、logo、片头片尾、安全区）
- 人工审核节点与版本对比
- 用量统计与额度控制
- Web 界面：上传、任务、结果

### P2：规模化（第 9 周以后）

- 多模态选段（画面、语音、文本联合打分）
- 素材智能打标与检索
- 工作流可视化编排
- 开放 API 与 Webhook
- 多机渲染与 GPU 队列
- 数据看板与 A/B 对比

## 7. 关键流程

```text
上传素材
  -> 选择工作流模板
  -> 创建任务（参数、规格、模板）
  -> 队列排队
  -> 节点执行（可重试、可续跑）
  -> 人工审核（可选）
  -> 导出多平台版本
  -> 下载 / 回传
```

## 8. 非功能需求

- 单任务 30 分钟内完成（30 分钟素材、10 条切片）
- 单机支持 2 到 4 个并发渲染任务，可配置
- 节点失败自动重试，重试不重复已完成的昂贵步骤
- 任务和节点状态可查询，事件可追踪
- 租户数据隔离，素材不出租户边界
- 上传大小、时长、分辨率有上限
- 模型调用有超时、重试和成本上限
- FFmpeg 调用不经过 shell 拼接，避免命令注入

## 9. 评测与指标

### 产品指标

- 成片合格率：人工判定可直接发布的比例
- 人工返工率：需要二次修改的任务占比
- 单条成片成本：模型加渲染加存储
- 端到端时延：P50 / P95
- 任务成功率与失败原因分布

### 评测集

第一阶段准备 30 到 50 条真实素材，覆盖口播、直播回放、产品展示、探店四类。每条标注：

- 可用的高光时间段
- 必须保留的信息点
- 不想要的片段（口误、冷场、竞品露出）

每次修改 Prompt 或选段策略，跑一遍评测集，记录合格率、召回率和平均成本。

## 10. 明确不做

- 不做专业级时间线编辑器
- 不做数字人
- 不做实时协作
- 不做移动端
- 第一版不做拖拽式编排
- 第一版不做自研模型训练

## 11. 里程碑

| 阶段 | 目标 | 验收标准 |
| --- | --- | --- |
| W1 | 引擎与媒体节点 | 命令行跑通探测、裁剪、导出 |
| W2 | ASR 与选段 | 生成字幕和 5 条候选片段 |
| W3 | 服务化 | API 创建任务，状态可查 |
| W4 | Web 闭环 | 上传到下载全流程可用 |
| W5 | 部署 | 云服务器可访问，重启不丢任务 |
| W6 | 评测与材料 | 评测报告、演示视频、简历描述 |
