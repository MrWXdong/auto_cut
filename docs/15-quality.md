# 生成质量与反馈闭环

## 1. 三层控制

质量不是一个参数能解决的，分成三层：

| 层 | 控制手段 |
| --- | --- |
| 模型与参数 | 模型档位、分辨率、候选数量、时长、seed、负面提示词 |
| 生成策略 | 提示词模板、参考图、best-of-N、失败重试、人工审核 |
| 产物检查 | 尺寸、文件完整性、文本长度、禁用词、关键词覆盖、用户反馈 |

## 2. 质量档位

| 档位 | 图片尺寸 | 候选数 | 分镜数 | 适用 |
| --- | --- | --- | --- | --- |
| `draft` | 720x1280 | 1 | 3 | 快速试方向 |
| `standard` | 1080x1920 | 2 | 5 | 日常交付 |
| `high` | 1440x2560 | 3 | 7 | 正式成片 |

模块任务里可以选择档位，任务参数会记录 `quality`。图片会生成多个候选，默认使用第一个，其余候选保留在任务结果里。

## 3. 质检

```text
POST /api/v1/quality/check
{
  "project_id": "...",
  "asset_id": "...",
  "required_keywords": ["墨绿色"],
  "banned_words": ["根治"]
}
```

返回：

```json
{
  "score": 100,
  "passed": true,
  "checks": [
    {"name": "length", "ok": true, "detail": "16 字符，最低 10"}
  ]
}
```

当前检查项：

- 文本：长度、禁用词、必备关键词
- SVG：画布尺寸、文件大小
- 其他素材：文件大小和文件存在性

## 4. 用户反馈

```text
POST /api/v1/quality/feedback
{
  "project_id": "...",
  "asset_id": "...",
  "rating": 2,
  "tags": ["文字错误", "节奏不好"],
  "comment": "封面文字看不清"
}
```

```text
GET /api/v1/quality/feedback
```

后台会汇总：

- 平均评分
- 负反馈数量
- 高频问题标签

这些数据用于后续调 Prompt、换模型、调整档位和补充评测集。

## 5. 后续接入

- 视觉模型打分：CLIP 相似度、美学评分、OCR 文字准确率
- 视频质检：FFprobe、黑帧检测、音画同步、字幕越界
- 自动重试：低分自动换 seed 或换模型重生成
- 人工审核：低分产物进入 `awaiting_review`

## 6. 当前限制

生图和音频还是本地占位实现，分数只能反映尺寸、文件完整性和文本规则。接入真实的通义、豆包、Seedream、TTS 后，质检分数才有真正的画面与音频意义。
